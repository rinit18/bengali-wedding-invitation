# শুভ বিবাহ — বাংলা ডিজিটাল বিয়ের আমন্ত্রণপত্র

একটি আধুনিক, সম্পূর্ণ বাংলা ও রেসপনসিভ ৩ডি ডিজিটাল বিয়ের আমন্ত্রণ ওয়েব অ্যাপ্লিকেশন (React + TypeScript + Vite + Tailwind CSS + Framer Motion + Three.js)।

## মূল বৈশিষ্ট্য
- **৩ডি হার্ডকভার প্রচ্ছদ (`EntranceGate`)**: ক্লিক করলে মলাট ঘুরে খুলে ভেতরের অধ্যায়ে প্রবেশ করে।
- **Three.js WebGL ৩ডি ব্যাকগ্রাউন্ড (`Scene3DBackground`)**: সোনার আলপনা বলয় ও সোনালি প্রদীপের কণা পটভূমিতে ভেসে থাকে।
- **৭টি রঙিন বাংলা অধ্যায়**: শুভ বিবাহ (হিরো), পাত্র ও পাত্রী (খড়খড়ি জানলা ও টোপর), বিবাহের শুভ নির্ঘণ্ট, গায়ে হলুদ, সাত পাক ও শুভ পরিণয়, রাজকীয় ভুরিভোজ এবং *"সবিনয় সাদর আমন্ত্রণ"* ও কাউন্টডাউনসহ শেষ প্রচ্ছদ।
- **মোবাইল ও ডেস্কটপ অপটিমাইজড**: সব ডেটা [`src/config/weddingData.ts`](src/config/weddingData.ts) থেকে সহজেই সম্পাদনা করা যায়।

## লোকাল রান ও বিল্ড
```bash
npm install
npm run dev
npm run build
```

## Vercel ডিপ্লয়মেন্ট
এই রিপোজিটরিতে `vercel.json` সংযুক্ত রয়েছে—সরাসরি Vercel-এ Import করে **Vite** ফ্রেমওয়ার্ক প্রিসেটে ডিপ্লয় করা যাবে।
